# Denys Sychov

Full-stack developer in Dublin, Ireland, with a strong core in Angular and ASP.NET Core. Outside work I build AI agents and autonomous-development tooling, in the open, in the [lifekit-hq](https://github.com/lifekit-hq) organization.

## Selected work

- [**lifekit-hq**](https://github.com/lifekit-hq): a self-hosted personal-AI stack, built as a federation of independently shippable repositories. Each product has its own repo, image, database, CI and releases; a platform repo deploys everything to one VPS, and a shared library carries the design system.
- [**finance-sentry**](https://github.com/lifekit-hq/finance-sentry): a personal finance platform covering bank accounts, crypto and brokerage, budgets, subscriptions and alerts. ASP.NET Core 9 (modular CQRS), Angular 21 and PostgreSQL; syncs TrueLayer, Monobank, Binance, Revolut X, Interactive Brokers and Inzhur; stored credentials are AES-256-GCM encrypted; versioned releases and an MCP interface for agents.
- [**lifekit-stack**](https://github.com/lifekit-hq/lifekit-stack): deploys the stack to a VPS with Docker Compose, with Prometheus, Loki, Tempo and Grafana for observability.
- [**lifekit-health**](https://github.com/lifekit-hq/lifekit-health): local-first CLI tools and agent skills for workout, nutrition and daily-state tracking (TypeScript).
- [**career-kit**](https://github.com/lifekit-hq/career-kit): YAML-driven CV tailoring over RenderCV, with one profile of facts and many role variants (Python).
- [**lifekit-common**](https://github.com/lifekit-hq/lifekit-common): the lifekit design system, with shared tokens and Angular components.

Most pull requests across lifekit-hq are opened by coding agents (Claude Code) that I direct: I set the goal and the definition of done, and CI plus a separate review step decide what merges.
